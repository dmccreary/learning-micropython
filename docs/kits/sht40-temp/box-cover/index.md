# SHT40 Kit — Box Cover Design

This page holds the printable box cover for the **SHT40 Temperature and
Humidity Kit**. The design uses a white background and high-contrast type,
so it does not drink your printer ink.

Print it, cut it out, and glue it to the front of the box you keep the kit
in. A bin of unlabelled boxes all look the same. A bin with covers on them
lets a student find the kit they want from across the room.

## Printable Cover Template

| Template size | Layout | Output | File link |
|---------------|--------|--------|-----------|
| **6" × 4" box front** | Two covers stacked on one 8.5" × 11" portrait sheet | **2 covers per sheet** | [Open the cover](../box-cover.html) |

The sheet gives you two identical covers, not a front and a back. Print one
sheet and you have covers for two boxes, or a spare for when the first one
gets glued on crooked.

## How to Print

1. Open the [printable cover](../box-cover.html) in your web browser.
2. Click the blue **Print 2 Covers** button at the top, or press
   `Ctrl + P` (`Cmd + P` on a Mac).
3. In the print dialog, choose:
      - **Destination**: your printer, or Save as PDF
      - **Paper size**: Letter (8.5 × 11 in)
      - **Orientation**: **Portrait**
      - **Scale**: **100%**, sometimes called Actual Size
      - **Background graphics**: **on**
4. Cut along the dashed corner marks to get each **6" × 4"** panel.

!!! warning "Do not let the printer shrink the page"
    If you leave the scale on "Fit to Printable Area", the cover comes out
    slightly too small and will not line up with a 6" × 4" box face. Set the
    scale to 100% before you print.

## What Is on the Cover

- **Title**: SHT40 Temp & Humidity
- **Series**: Learning MicroPython
- **Photo**: the assembled kit, with a fingertip on the sensor and the
  NeoPixel strip lit from blue through green and yellow to orange
- **Sensor spec**: ±0.2 °C and ±1.8 % relative humidity

### Audience Badges

- Ages 10+ to adult
- Students • Libraries • Clubs
- No soldering required

### Feature Highlights

1. Measure heat and humidity in real time
2. Watch your fingertip paint a color bar
3. Graph live data right inside Thonny
4. Learn how to use the I2C bus to gather sensor data
5. Five MicroPython labs, no soldering

## What Goes in the Box

The cover advertises the color bar demo, so the box needs the NeoPixel
strip as well as the sensor.

| Part | Notes |
|------|-------|
| Raspberry Pi Pico | With MicroPython already installed |
| SHT40 breakout board | About $1.65 on eBay |
| 8-pixel NeoPixel stick | Needed for the color bar demo on the cover |
| Solderless breadboard | Half-size is plenty |
| Jumper wires | 4 for the sensor, 3 more for the strip |
| USB cable | Must be a data cable, not charge-only |

The full build instructions are in the
[SHT40 kit lesson](../index.md).
